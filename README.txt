MONKEE BLUE GALAXY - Gamepad Viewer skin (PS5 / DualSense)
==========================================================

YOUR LINK (unchanged):
  https://gamepadviewer.com/?p=1&css=https://sethgood.github.io/ROULZY.github/skin.css

HOW TO UPDATE
 1. Open your GitHub repo (sethgood/ROULZY.github) > Add file > Upload files.
 2. Drag in EVERY file from this folder (skin.css, body.webp, body-static.png,
    stick.png and all the other .png files). Same names = they replace the old ones.
    Do not upload only some of them - the sizes and positions must match.
 3. Commit changes, wait 1-3 minutes for GitHub Pages to update.
 4. Check these open:
      https://sethgood.github.io/ROULZY.github/skin.css
      https://sethgood.github.io/ROULZY.github/body.webp
 5. Reload the Gamepad Viewer link (Ctrl+F5). In OBS: Browser Source >
    "Refresh cache of current page". Size: 1049 wide x 846 high.
    Still seeing the old skin? Use ...skin.css%3Fv=5 at the end of the link.

NOTES
 - Touchpad and PS button only light up if your setup passes them through.
 - Layout approach based on CrazyGrape's DualSense skin (CC BY 3.0 US).
   PlayStation / DualSense designs belong to Sony.
